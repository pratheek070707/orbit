# Ask Orbit

Ask Orbit answers questions using repository evidence available to the workspace. Depending on the request, the evidence can include the selected repository's README, metadata, recent activity, and an optional source file that the user selects.

## Getting useful answers

1. Select the repository that matches the question.
2. Ask a specific question, such as what a named module does or which health check needs attention.
3. Include a source file when the answer depends on implementation details.
4. Check cited repository evidence before acting on a recommendation.

Orbit should distinguish repository facts from suggestions and say when evidence is missing. Source file contents are sent to the configured AI provider when selected. Model usage may incur charges under that provider's account. Never include secrets or credentials in prompts or source files.
