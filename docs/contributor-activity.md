# Orbit contributor activity

Orbit summarizes contribution activity from the GitHub account connected to the workspace. It uses repository commit history and available pull request activity to help compare work across repositories.

## Reading the activity view

- The contribution calendar groups dated activity into days. A quiet day means GitHub returned no qualifying activity for that date.
- Repository insights show available contributors and recent activity for the selected repository.
- Language totals come from GitHub repository metadata and may be incomplete when GitHub has not finished language analysis.

## Data boundaries

Orbit displays activity returned by GitHub for the connected account and granted permissions. It does not infer unreported work, private activity outside the authorized account, or exact time spent coding. Counts should be read as recorded GitHub events, not as a measure of effort.
