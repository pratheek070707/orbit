# Orbit developer ecosystem map

Orbit's ecosystem map helps explore relationships represented by the GitHub data available to the connected workspace. Repository, contributor, and programming-language nodes can be connected when the underlying metadata shows a shared relationship.

## How to read the map

- Repository nodes represent repositories returned by GitHub.
- Contributor nodes represent accounts associated with available repository activity.
- Language nodes summarize languages reported for those repositories.
- Edges show the specific relationship used by the visualization; they should not be read as proof of collaboration beyond the displayed GitHub evidence.

Use the map to discover shared contributors or languages, then open the repository or profile to inspect the source details. Sparse or missing connections can reflect permissions or missing GitHub metadata.
